## 🚀 How to Use

### ⚠️ First-Time Setup

**Important:** Install the new `schedule` dependency first:

```bash
# Option 1: Rebuild container (recommended)
docker-compose down
docker-compose build backend
docker-compose up -d

# Option 2: Install in running container
docker-compose exec backend pip install schedule

# Option 3: Use start.sh (handles everything)
./start.sh
```

See **[SPRINT_7_SETUP.md](SPRINT_7_SETUP.md)** for detailed setup instructions.

### Quick Start

```bash
# Run manually (easiest way)
./run_wellness_outreach.sh

# Or directly via Docker
docker-compose exec backend python -m app.wellness_outreach

# Run tests first to verify everything works
docker-compose exec backend python -m app.test_wellness_outreach
```

### Schedule Automatically

```bash
# Run as continuous service (recommended)
docker-compose exec backend python -m app.wellness_scheduler

# Or add to docker-compose.yml (see docker-compose.wellness.example.yml)
```

## 🎯 Key Features

### Intelligent Pet Identification

- Finds pets with no future bookings
- Identifies pets with no visit in 12+ months
- Automatically filters out recently seen pets

### Smart Scheduling

- Searches 7 days ahead (configurable)
- Checks all staff members
- Respects business hours (9 AM - 5 PM)
- Excludes weekends automatically

### AI-Powered Matching

- Uses vector similarity to match client preferences
- Falls back gracefully if no preferences exist
- Considers time-of-day preferences (morning/afternoon)

### Personalized Emails

- Generated by Ollama LLM (llama3)
- Includes pet name, species, owner name
- Suggests specific appointment time and vet
- Warm, professional tone
- Fallback template if LLM fails

### Robust Execution

- Per-pet error isolation
- Comprehensive error logging
- Graceful degradation
- Clean database session management

## 🚢 Production Deployment

### Option 1: Manual Cron Job

Add to host crontab:

```bash
0 8 * * 1 cd /path/to/Interpaws && ./run_wellness_outreach.sh >> /var/log/interpaws-outreach.log 2>&1
```

### Option 2: Docker Service (Recommended)

Add to `docker-compose.yml`:

```yaml
wellness-scheduler:
  build: ./backend
  command: python -m app.wellness_scheduler
  depends_on: [db, ollama, backend]
  environment:
    - DATABASE_URL=postgresql://user:password@db/interpawsdb
    - OLLAMA_HOST=http://ollama:11434
  restart: unless-stopped
```

Then: `docker-compose up -d wellness-scheduler`
